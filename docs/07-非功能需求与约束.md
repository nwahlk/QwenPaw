## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **问答端点 P95 延迟** | < **5000ms** | `response_time_ms` 字段 | `03` 4 |
| 会话管理端点延迟 | < 500ms | 服务端计时 | JSON I/O < 10ms |
| 前端页面首屏加载 | < **2000ms** | 浏览器 Performance API（DOMContentLoaded） | `05` AC-001-02 |
| JSON 文件读写 | < **50ms** | Storage 层计时（单次 RMW 周期） | `08` §5 JSON 存储 |
| 会话列表渲染 | < **300ms** | 从 `GET /sessions` 返回到 DOM 渲染完成 | `05` AC-001-02 |
| 历史记录加载 | < **500ms** | 从点击会话到问答记录渲染完成 | `05` AC-003-01 |

### 1.2 降级策略

**示例 — 三级降级链**：

```
CoPawAgent.ask(query, session_id)
  ├─[1] CoPaw 桥接 → answer_source='copaw', llm_used=True
  ├─[2] 百炼 DashScope → answer_source='bailian', llm_used=True
  └─[3] 离线演示兜底 → answer_source='demo', llm_used=False
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按 CoPaw → 百炼 → Demo 顺序尝试 |
| 降级**静默执行** | 不抛异常，通过 `answer_source` 标识 |
| Demo 模式**始终可用** | 无外部依赖，纯字符串拼接 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask，不设 HA |
| MTTR | < 5 分钟 | 重启 Flask 进程即可恢复 |
| 故障模式 | 恢复方式 | 来源 |

| 故障模式 | 恢复方式 | 来源 |
|----------|----------|------|
| CoPaw 桥接不可达 | 静默降级至百炼，answer_source 标识为 bailian | `03` §5 风险-1、`04` R-04 |
| 百炼 API Key 失效 | 静默降级至 Demo 模式，answer_source 标识为 demo | `03` §5 风险-1、`05` AC-002-03 |
| JSON 数据文件损坏 | /health 返回 degraded，手动恢复数据目录后重启 | `05` AC-004-02 |
| 数据目录不可写 | /health 返回 degraded 而非 healthy，拒绝写操作并返回 500 | `05` AC-004-02 |
| Flask 进程崩溃 | 手动重启进程（MTTR < 5 分钟），会话数据不丢失（持久化在 JSON 文件） | `03` §5 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 |
|------|--------------|----------|
| 400 | `EMPTY_QUERY` | query 为空/空白/null |
| 400 | `INVALID_QUERY` | query >500 字符 或 缺少 session_id |
| 500 | `UPSTREAM_ERROR` | Agent 编排内部异常 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | Workshop 教学版 |
| CORS | 全开放 | 生产需白名单 |
| 速率限制 | 无 | 教学场景不限速 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| LLM API Key | 环境变量存储（`.env`），禁止硬编码 |
| 用户查询 | 仅存储在本地 JSON，不传输到第三方（LLM 除外） |
| LLM 回答内容 | 仅持久化到本地 qa_records.json，不回传至其他系统 | `04` R-03 |
| 会话元数据 | 本地 sessions.json 存储，删除时级联清除关联记录，零残留 | `04` R-05、`05` AC-001-03 |
| traceId | 仅用于链路追踪，不包含用户身份或业务敏感信息 | `09` §2 |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `query` 最小长度 | 1 字符 | `04` R-02 |
| `query` 最大长度 | 500 字符 | `04` R-02 |
| `session_id` 必填 | 非空字符串 | `04` R-01 |
| `title` 默认值 | 未传入时默认为 "新会话"，≤ 23 字符 | `09` §4、`10` §3 |
| `title` 首次问答自动重命名 | query_count 从 0→1 时，title = query 前 20 字 + "..." | `10` §6 |

### 5.2 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `llm_used` | `boolean` | 必须为 True/False，不得为字符串 |
| `answer_source` | `string` | 枚举：copaw \| bailian \| demo |
| `response_time_ms` | `integer` | ≥ 0，单位毫秒，来源 = `09` §3 |
| `model` | `string\|null` | LLM 模型标识，Demo 模式下为 null，来源 = `09` §3 |
| `session_id` | `string` (UUID) | 符合 UUID 格式，来源 = `04` R-01 |
| `query_count` | `integer` | ≥ 0，随 add_record 自增，来源 = `10` §3 |
| `created_at` / `updated_at` | `string` (ISO-8601) | UTC+Z 格式，来源 = `10` §3 |
