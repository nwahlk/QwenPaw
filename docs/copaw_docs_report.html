01 项目概述

CoPaw 是一个个人 AI 助理，安装极简，支持本地与云端部署，多端接入，能力通过 Skills 轻松扩展。

由你掌控
记忆与个性化完全由你掌控，支持本地或云端部署，无第三方托管
Skills 扩展
内置定时任务、PDF/Office 处理、新闻摘要等；自定义技能自动加载
多智能体协作
创建多个独立智能体，各司其职，互相通信共同完成复杂任务
全域触达
钉钉、飞书、微信、Discord、Telegram、QQ、iMessage 等 14 个频道

快速开始

pip install copaw
copaw init --defaults
copaw app

打开 http://127.0.0.1:8088/ 即可使用。

02 系统架构

11 多智能体系统

CoPaw 支持创建多个独立智能体，各司其职，通过协作技能互相通信共同完成复杂任务。

使用场景

场景Agent 配置
内容创作研究员 Agent（搜集资料）+ 写手 Agent（生成内容）
代码开发架构师（设计方案）+ 开发者（编写代码）+ 审查员（代码审查）
信息监控监控 Agent（定时检索）+ 分析 Agent（数据分析）+ 通知 Agent（推送摘要）

配置示例

┌─────────────────────────────────────┐ │ 技能安全扫描 (Skill Scanner) │ 安装前扫描：提示词注入、命令注入、 │ │ 硬编码密钥、数据外泄 ├─────────────────────────────────────┤ │ 工具防护 (Tool Guard) │ 运行时拦截：危险 Shell 命令、 │ │ fork 炸弹、反向 Shell ├─────────────────────────────────────┤ │ 文件访问守卫 (File Access Guard) │ 路径限制：~/.ssh、密钥文件、 │ │ 系统目录等敏感路径 ├─────────────────────────────────────┤ │ Web 登录认证 (Optional Auth) │ 可选的控制台登录防护 ├─────────────────────────────────────┤ │ 本地部署 │ 所有数据存储在本地，无第三方托管 └─────────────────────────────────────┘

14 常见问题

问题解决方案
pip install 报错确保 Python 3.10~3.13，或使用脚本安装/Docker
Windows LTSC 安装失败使用 CMD 安装或手动安装 uv
前端控制台空白重新构建前端：cd console && npm ci && npm run build
无法访问 8088 端口检查端口占用，更换端口或检查防火墙
对话无响应确认 API Key 有效，检查网络和额度
Docker 中无法连接 Ollama使用 host.docker.internal 替代 localhost
自定义技能未加载确认包含 SKILL.md，放在 skills/ 目录下，重启服务
更新后功能异常重新构建前端、重新安装 Python 包、清除浏览器缓存

16 全景分析摘要

关键设计模式

模式说明
多代理隔离每个 Agent 运行在独立 Workspace 中，拥有完整的运行时组件栈
插件化架构渠道和技能均遵循注册-发现-加载的插件模式，支持热重载
优先级队列消息通过四级优先级路由，确保关键命令可抢占普通对话
流式优先所有 Agent 响应使用 SSE 流式传输，支持 TaskTracker 取消
零停机热重载配置变更时原子替换实例，不影响正在处理的请求
安全纵深防御Tool Guard (运行时) + Skill Scanner (安装时) 双层安全
声明式服务管理ServiceManager 通过优先级和依赖关系管理组件生命周期
