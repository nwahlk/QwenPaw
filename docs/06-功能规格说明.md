## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击 sidebar 某条会话 | `GET /sessions/<id>/records` | 高亮选中项，main 区加载该会话问答记录（状态 B 或 C），input-area 聚焦 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 常见问题** | 有会话 && 无记录 | 显示 3~4 个常见问题卡片网格（如"某公司最新评级？""目标价是多少？"），点击任一卡片自动填入 query-input 并触发 `POST /ask` 提交 |
| **C 对话历史** | 有记录 | 按时间正序渲染记录卡片列表，每条卡片包含：① 用户问题气泡（右侧）② AI 回答气泡（左侧）③ 来源标签（answer_source）④ 响应耗时（response_time_ms）⑤ 时间戳（timestamp），自动滚动到最新一条 |

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长" |
| `SESSION_NOT_FOUND` | 404 | 错误提示："会话不存在，请刷新页面" |
| `SERVER_ERROR` | 500 | 错误提示："服务器繁忙，请稍后重试" |
| `NETWORK_ERROR` | — | 错误提示："网络连接失败，请检查网络" |
| `LLM_TIMEOUT` | 504 | 错误提示："AI 响应超时，已返回离线回答" |

## 7. 状态管理

> React `useState` Hooks，列出你的组件需要管理哪些状态。

| State 变量 | 类型 | 初始值 | 用途 |
|------------|------|--------|------|
| `sessions` | `Session[]` | `[]` | 会话列表 |
| `currentSession` | `Session\|null` | `null` | 当前选中会话 |
| `records` | `QARecord[]` | `[]` | 当前会话的问答记录列表 |
| `loading` | `boolean` | `false` | 问答提交中 loading 状态，控制发送按钮 disabled |
| `query` | `string` | `""` | 输入框当前文本 |
| `capabilities` | `object\|null` | `null` | 能力探测结果（copaw_configured / bailian_configured / model） |
| `error` | `string\|null` | `null` | 当前错误提示文案，非空时显示 toast |
| `sessionLoading` | `boolean` | `true` | 会话列表加载中状态 |
