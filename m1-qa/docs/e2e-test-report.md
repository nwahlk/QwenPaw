## 3. 缺陷与建议

### 3.1 问题清单

| # | 严重度 | 模块 | 描述 | 建议 |
|---|--------|------|------|------|
| 1 | **中** | 研报问答 | 提问后返回"请求失败"，LLM 服务未启用 | 配置 `DASHSCOPE_API_KEY` 环境变量 |
| 2 | **低** | 知识库 | 已入库文档 0 条，问答无法检索到依据 | 导入示例研报/公告文档 |

### 3.2 优化建议

1. **生产部署前**：完成百炼 API 密钥配置，确保 LLM 问答链路畅通
2. **知识库冷启动**：预置一批示例研报/合规制度文档，便于演示完整问答流程
3. **错误提示优化**：问答失败时建议显示具体原因（如"LLM 服务未配置"），而非通用的"请求失败"
